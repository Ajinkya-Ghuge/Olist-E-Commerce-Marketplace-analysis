# Olist Analytics Pro - Project Plan

## Project Overview
**Project Name:** Olist Analytics Pro — Enterprise E-Commerce Intelligence Platform

**Business Objective:**  
Build a comprehensive data analytics solution to investigate Brazilian e-commerce marketplace performance across revenue, products, customers, sellers, delivery, and satisfaction metrics.

**Target Role:** Senior Data Analyst / Business Intelligence Analyst

---

## Data Source
- **Original Dataset:** Brazilian Olist E-Commerce (Kaggle)
- **Location:** `dataset/` folder
- **Key Files:** 9 CSV files covering orders, customers, products, sellers, payments, reviews, and geolocation
